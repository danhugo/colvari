## OpenCode (`opencode`)

- Invocation: OpenCode uses `profileRuntime`, whose `buildArgs` normalizes the node, derives a runtime profile from the binary, maps provider/model IDs, writes per-run file-method MCP config when needed, builds profile args from the profile, appends extra args and may move long prompts to stdin. `app/src/runtimes.js:52` `app/src/runtimes.js:61` `app/src/runtimes.js:62` `app/src/runtimes.js:65` `app/src/runtimes.js:66` `app/src/runtimes.js:67` `app/src/runtimes.js:74` `app/src/runtimes.js:76` `app/src/runtimes.js:86` `app/src/runtimes.js:87` `app/src/runtimes.js:91` `app/src/runtimes.js:92`

- Board MCP: the OpenCode comment says per-run `OPENCODE_CONFIG` carries board MCP, and the profile-runtime capability reports MCP support only when the derived profile method is not `none`. `app/src/runtimes.js:136` `app/src/runtimes.js:137` `app/src/runtimes.js:138` `app/src/runtimes.js:43` `app/src/runtimes.js:57` `app/src/runtimes.js:58`
